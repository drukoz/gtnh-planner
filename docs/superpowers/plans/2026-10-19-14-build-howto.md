**Goal:** The user's report — *"what about the recipes for the electronic circuit where we are missing the molten tin recipe"* — fixed for the whole build list: every machine-made part of the "to build" list says what makes it, the build steps tell the group to make each one in order ("Make 720 L Molten Tin from 5× Tin Dust in a Basic Fluid Extractor"), the build totals stop multiplying whole runs per part and stop listing made goods (cut off at the tree's depth, or caught in a tie with their own packed form) as base materials, "we already make this" items stop being a cheap source the running line recycles into steel, and a placed line's layout parts get the same breakdown and steps.

**Architecture:** Server: the build-list breakdown (`bom.ts` `expandWith`) settles one recipe per good over its recipe book cheapest first — leaves at their cost, a recipe offering what it makes once everything it consumes has settled, at its gross cost (no credit for the outputs the breakdown throws away), a pinned good by its pin while that settles it — so the choices form a DAG with no depth cap, no lineage check and no tie that unpacks a good's own packed form (`howto.ts` `settleRecipes`). Every node records how (`BomLine.made`: recipe, machine, runs, circuit, held parts, cleanroom) with a machine chosen in the order owned → built by this line → one still needed; a good nothing can make there is `unmade`, by cause. A pooled pass over those choices sums every made good's demand over the whole list before rounding whole runs (`poolMakes`), which gives the build totals and one `make` build step per part, ordered inputs-first and batched by machine (`steps.ts` `partSteps`); only the tree shown stops at 12 levels. A placed line is broken down once more as a whole — the plan's own lines and the layout's parts together (Plan 5's `finishPlan`) — so its totals and part steps pool both. Stop items are priced at what making them on their own costs (add-on 12's machine prices too), and the recycling rule also catches smelting a finished part back into another material's metal. Client: the Materials page shows "made in <machine> from <parts>" on every made row and offers the flow view's Swap recipe, extracted into a shared component.

4. **A recipe pin on a good the running line also makes**: the build list and the flow view share `recipeChoice[key]`; every node of that good follows it while the pin settles it; a pin that needs the good itself (directly or through its parts) is dropped for the build list and the good falls back to its other producers, which the book keeps beside the pin, so a pin never turns a part into an import — Task 3 `it('uses a pinned recipe for every node of that good')`, `it('falls back from a pin that needs the good itself')`.
5. **Re-planning with another amount or batch keeps the ticks on make steps**: ids name the good, never an amount or a position — Task 5 `it('keeps step ids when the amounts change')`.
6. **A chain deeper than the tree shows** (12 levels; on the user's line today 46 nodes sit at that depth with no children, and 7 made goods among them are counted as base materials for that reason alone): every good below the cut still gets its recipe, its pooled amount and its step, and the cut node keeps its `made` — never a base material with no step — Task 3 `it('chooses the recipes below the depth the list shows')`, Task 4 `it('pools the parts below the depth the list shows')`.

## Architecture change requests

All of these become **one** architecture §11 entry, **41** (Task 1 Step 4):

1. `src/shared/types/plan.ts`: `interface BomMachine { mteId: number; name: string; tier: number; source: 'owned' | 'line' | 'new' | 'first' }` and `interface BomMade { recipeId: string; mapId: string; machine: BomMachine | 'crafting table'; runs: number; circuit?: number; nonConsumed?: StuffKey[]; cleanroom?: true }`; `BomLine.made?: BomMade` on every node of a good the breakdown makes (a node the tree cuts at its 12-level cap keeps it; never on a leaf); `runs` = that node's whole runs; `cleanroom` = the recipe needs one; `source`: `owned` = the group has one (world scan, `ownedManual`, a step's owned machines; reuse settings do not apply to a one-off job), `line` = a type this line adds, `new` = neither (the cheapest tier that runs it), `first` = only this line's own unit could, but its build needs this part. A good is made one way across the whole build list: the breakdown settles one recipe per good over its recipe book (`howto.ts` `settleRecipes`) cheapest first — leaves at their leaf cost (in key order; a base material out of reach at Infinity), a recipe whose consumed goods have all settled offering each good it makes (an ore-dictionary slot's convert recipe its slot) at its gross cost per unit, the cheapest offer settling a good (equal costs: the offer that burns less free input per unit made — water, lava, air or cobblestone, each unit counting 1 — then the offer made first, then the smaller recipe id; the controller's tie-break ruling 93, which keeps the 2.9 export's Aluminium Ingot on its plain EBF recipe where its gas variants, made from free Air, tie it) — so a recipe settles a good only after all it consumes has settled, the choices form a DAG with no depth cap, and every node of a good and every ore-dictionary slot uses its settled recipe or option. A pinned good is offered by its pin alone; while one that never settles so has another recipe in the book, the first such pin by key is dropped and the book settles again. The book keeps a pinned good's normally kept producers beside the pinned recipe (`CandidateOptions.pinnedBeside`); the line's own graph keeps today's rule (only the pin).
2. `BomLine.unmade?: 'no-recipe' | 'own-chain'` on every node and the total of a good the line cannot buy and the breakdown cannot settle: `own-chain` = a recipe of it consumes an unsettled good from which the book's recipes lead back to it (swap a recipe above it, or import it); `no-recipe` = anything else (no recipe here makes it, or its recipes need parts nothing here makes: import it) — also a good above a part the breakdown's graph never expanded because it stopped at its recipe cap, beside the build list's `graph-too-big` warning.
3. `Plan.buildAlternatives?: Record<StuffKey, PlanStep['alternatives']>`: the swap list of every made build part — every recipe of the book for it whose consumed goods all settled, at a finite gross cost (a pinned good's other producers too; a recipe above a base material out of reach costs Infinity and is left out, as a step's swap list keeps finite costs only, and a part left with none has no swap list), by gross cost at the settled costs, then id, each with `recipeParts`; pins stay `PlanSettings.recipeChoice[key]`, shared with the running line.
4. Pooled totals (amends §11.15 and plan 09's `BomLine.neededFor`): `Plan.buildTotals` and `expandBomLines(...).totals` sum each made good's demand over the choices' DAG for the whole list (below the tree's depth cap too) before rounding whole runs (`howto.ts` `poolMakes`); `neededFor` amounts are each top-level line's exact (unrounded) share scaled to the pooled amount, the last one taking the remainder. The tree (`buildList` children) keeps whole runs per node.
5. `BuildStep.kind` gains `'make'`. After `gather`, one step per made build part: the top-level line's own `craft:<key>` id or `make:<key>`, kind `make` (a machine) or `craft` (a crafting table), and kind `gather` for an `unmade` part ("Get …", worded by its cause); ordered inputs first, a machine this line builds after its own craft and structure steps, batched by machine. A one-off craft of the build list says "at a crafting table" (entry 39: one-off crafting in the build list stays by hand). Plan 5's `mergeBuildSteps` keeps `make` before the layout's steps (`BEFORE_LAYOUT`).

const MACHINE_ITEMS = new WeakMap<Pack, ReadonlyMap<StuffKey, Machine>>();

/** Each machine's item → the machine (the lowest mteId when several share an item), once per pack. */
function machineItems(pack: Pack): ReadonlyMap<StuffKey, Machine> {
  let byItem = MACHINE_ITEMS.get(pack);
  if (byItem === undefined) {
    const map = new Map<StuffKey, Machine>();
    for (const m of [...pack.machines.values()].sort((a, b) => a.mteId - b.mteId)) if (!map.has(m.itemKey)) map.set(m.itemKey, m);
    byItem = map;
    MACHINE_ITEMS.set(pack, byItem);

 * name, `<that name> (variant <meta>)`; else `<id>` at meta 0 and `<id> (meta <meta>)` above it. A key that is no plain
 * item key (a fluid, an NBT variant) keeps `pack.nameOf`.
 */
export function partName(pack: Pack, key: StuffKey): string {
  const named = pack.nameOf(key);
  if (named !== key || isFluidKey(key) || key.includes('#') || !/@\d+$/.test(key)) return named;

  const { id, meta } = parseItemKey(key);
  if (meta === 0) return id;
  const base = pack.nameOf(`${id}@0`);
  return base !== `${id}@0` ? `${base} (variant ${meta})` : `${id} (meta ${meta})`;

 * plain price when nothing here makes it. Worked out once per pack and pricing context, whatever keys are asked, for at

function stopItemCosts(pack: Pack, s: PlanSettings, ctx: PlanContext, basis: ReturnType<typeof planBasis>): Promise<(key: StuffKey) => number> {
  const stops = s.stopItems.filter((key) => !Object.hasOwn(s.costOverrides, key));
  if (stops.length === 0) return Promise.resolve((key: StuffKey) => basis.prices.price(key));
  const id = `${settingsHash(s)}|${basisContextKey(ctx)}`;

  if (memo === undefined) {
    memo = new Map();
    STOP_COSTS.set(pack, memo);
  }
  const hit = memo.get(id);
  if (hit !== undefined) {
    memo.delete(id);
    memo.set(id, hit);
    return hit;
  }
  const costs = (async (): Promise<(key: StuffKey) => number> => {
    await yieldToEventLoop();
    const open: PlanSettings = { ...s, stopItems: [] };
    const graph = buildCandidates(pack, open, basis.env, makeLeafOracle(pack, open, basis.avail, basis.prices), stops);
    const made = await standaloneCosts(graph, stops, [], pack.fluidContainers ?? []);
    const floor = stopFloor(pack, basis.prices);
    return (key) => {
      const cost = made.get(key)?.cost;

const BASE_FORM_PREFIXES: readonly string[] = ['ingot', 'nugget', 'block'];

const MADE_OF = new WeakMap<Pack, Map<string, boolean>>();

/** Whether some recipe of the pack that makes `key` consumes a GT item of one of `metals` (memoized per pack). */
function madeOfMetal(pack: Pack, key: StuffKey, metals: ReadonlySet<string>): boolean {
  let memo = MADE_OF.get(pack);
  if (memo === undefined) MADE_OF.set(pack, (memo = new Map()));
  const id = `${key}|${[...metals].sort().join(',')}`;
  let made = memo.get(id);
  if (made === undefined) {
    made = (pack.producers.get(key) ?? []).some((i) => (pack.recipes[i]?.inputs ?? [])
      .some((ing) => ing.consumed && ing.options.some((o) => metals.has(pack.items.get(o.key)?.gt?.material ?? ''))));
    memo.set(id, made);
  }
  return made;
}

/**
 * A smelting recipe that melts a finished part back into metal (architecture §11 entry 41 (7)): GT's recycling, which its
 * unificator adds to the furnace list without a recycling flag. Its one consumed input is a GT part (no ore-processing
 * prefix) smelted into GT forms of its own material, or one that is no base form (`BASE_FORM_PREFIXES`) smelted into any
 * material's forms — a magnetic or pig-iron part into its base metal, which priced a stopped Steel Rod at 0 on the 2.9
 * export (128 such recipes there that the first rule missed) — or a non-GT item that the pack makes from one of the
 * outputs' materials (bars made from rods, tools, machines: 214 of the export's 344 smelts of a non-GT item into GT
 * forms; native clusters, poor ores, Red Iron Compound, wood and clay stay). A plan would otherwise make Polyethylene Bars
 * by crafting sheets into pipes and smelting those.
 */
function smeltsBack(r: Recipe, pack: Pack): boolean {
  if (!r.maps.some((map) => SMELTING_MAPS.has(map))) return false;
  const consumed = r.inputs.filter((ing) => ing.consumed);
  if (consumed.length !== 1 || r.outputs.length === 0) return false;
  const material = (key: StuffKey): { prefix: string; material: string } | undefined => pack.items.get(key)?.gt;
  const metals = new Set<string>();
  for (const p of r.outputs) {
    const m = material(p.key)?.material;
    if (m === undefined) return false;
    metals.add(m);
  }
  return consumed[0]!.options.some((o) => {
    const input = material(o.key);
    if (input === undefined) return madeOfMetal(pack, o.key, metals);
    if (PROCESSING_PREFIXES.some((prefix) => input.prefix.startsWith(prefix))) return false;
    return (metals.size === 1 && metals.has(input.material)) || !BASE_FORM_PREFIXES.some((prefix) => input.prefix.startsWith(prefix));
  });
}

function byString(a: string, b: string): number {

const MAKERS = new WeakMap<CandidateGraph, ReadonlyMap<StuffKey, readonly LpRecipe[]>>();

/** The recipes of `graph` that make each good (convert recipes make their ore-dictionary slot), by id; once per graph. */
export function makersOf(graph: CandidateGraph): ReadonlyMap<StuffKey, readonly LpRecipe[]> {

        if (list === undefined) map.set(key, [lp]);

      }
    }

  }

type Entry = [cost: number, free: number, seq: number, key: StuffKey, lp: LpRecipe | null];

/** A binary min-heap of offers by cost, then the free input they burn, then the order they were made in. */
class OfferHeap {
  readonly #items: Entry[] = [];
  static #before(a: Entry, b: Entry): boolean {
    return a[0] < b[0] || (a[0] === b[0] && (a[1] < b[1] || (a[1] === b[1] && a[2] < b[2])));
  }
  push(e: Entry): void {
    const a = this.#items;
    a.push(e);
    for (let i = a.length - 1; i > 0;) {
      const up = (i - 1) >> 1;
      if (!OfferHeap.#before(a[i] as Entry, a[up] as Entry)) break;
      [a[i], a[up]] = [a[up] as Entry, a[i] as Entry];
      i = up;
    }
  }
  pop(): Entry | undefined {
    const a = this.#items;
    const top = a[0];
    const last = a.pop();
    if (a.length > 0 && last !== undefined) {
      a[0] = last;
      for (let i = 0; ;) {
        const l = 2 * i + 1;
        const r = l + 1;
        let m = i;
        if (l < a.length && OfferHeap.#before(a[l] as Entry, a[m] as Entry)) m = l;
        if (r < a.length && OfferHeap.#before(a[r] as Entry, a[m] as Entry)) m = r;
        if (m === i) break;
        [a[i], a[m]] = [a[m] as Entry, a[i] as Entry];
        i = m;
      }
    }
    return top;
  }
}

/** One settle of `graph` with `pins` (good → pinned recipe id). */
function settleOnce(graph: CandidateGraph, opts: SettleOptions, pins: ReadonlyMap<StuffKey, string>): Omit<Settled, 'droppedPins'> {
  const keys = new Set<StuffKey>(graph.goods.keys());
  const waiting = new Map<string, number>();
  const consumers = new Map<StuffKey, LpRecipe[]>();
  for (const lp of graph.recipes) {
    let n = 0;
    for (const [key, c] of lp.coeffs) {
      keys.add(key);
      if (c >= 0) continue;
      n++;
      const list = consumers.get(key);
      if (list === undefined) consumers.set(key, [lp]);
      else list.push(lp);
    }
    waiting.set(lp.id, n);
  }
  const heap = new OfferHeap();
  let seq = 0;
  const cost = new Map<StuffKey, number>();
  const free = new Map<StuffKey, number>();
  const recipe = new Map<StuffKey, { lp: LpRecipe; perRun: number }>();
  const option = new Map<StuffKey, { key: StuffKey; amount: number }>();
  const offer = (lp: LpRecipe): void => {
    let total = 0;
    let burnt = 0;
    for (const [key, c] of lp.coeffs) {
      if (c >= 0) continue;
      total -= c * (cost.get(key) as number);
      burnt -= c * (free.get(key) as number);
    }
    for (const [key, c] of lp.coeffs) {
      if (c <= 0 || cost.has(key) || opts.leafCost(key) !== null) continue;
      const pin = pins.get(key);
      if (pin !== undefined && pin !== lp.id) continue;
      if (opts.offers !== undefined && !opts.offers(lp, key)) continue;
      heap.push([total / c, burnt / c, seq++, key, lp]);
    }
  };
  for (const key of [...keys].sort(byString)) {
    const leaf = opts.leafCost(key);
    if (leaf !== null) heap.push([leaf, opts.free?.(key) ?? 0, seq++, key, null]);
  }
  for (const lp of graph.recipes) if (waiting.get(lp.id) === 0) offer(lp);
  for (let e = heap.pop(); e !== undefined; e = heap.pop()) {
    const [c, f, , key, lp] = e;
    if (cost.has(key)) continue;
    cost.set(key, c);
    free.set(key, f);
    if (lp !== null) {
      if (lp.kind === 'convert') {
        const used = lp.coeffs.find(([, k]) => k < 0) as [StuffKey, number];
        option.set(key, { key: used[0], amount: -used[1] });
      } else {
        recipe.set(key, { lp, perRun: madePerRun(lp, key) });
      }
    }
    for (const next of consumers.get(key) ?? []) {
      const left = (waiting.get(next.id) as number) - 1;
      waiting.set(next.id, left);
      if (left === 0) offer(next);
    }
  }
  return { recipe, option, cost, free };
}

/**
 * One recipe per good of the breakdown's book (architecture §11 entry 41 (1)), settled cheapest first as the candidate
 * walk's estimate settles goods: a leaf settles at its leaf cost (leaves in key order); a recipe whose consumed goods have
 * all settled offers each good it makes, an ore-dictionary slot's convert recipe its slot, at its gross cost per unit —
 * what its consumed goods cost at their settled costs over what one run makes of the good, no credit for its other outputs
 * (the breakdown throws them away); the cheapest offer settles a good, at equal cost the one that burns less free input
 * per unit made (`SettleOptions.free`, worked out beside the cost), then the one made first (its recipe was ready first,
 * then the smaller recipe id), and every good settles once. So a recipe settles a good only after all it consumes has
 * settled: the choices form a DAG and no recipe consumes a good it is being made for, at any depth; a good's own packed
 * form or a stand-in pressed from the real thing settles after the real thing and loses every tie to it. A pinned good
 * is offered by its pin alone; while one that never settles so has another recipe in the book, the pin of the first
 * such good by key is dropped and the book settles again.
 */
export function settleRecipes(graph: CandidateGraph, opts: SettleOptions): Settled {
  const makers = makersOf(graph);
  const pins = new Map<StuffKey, string>();
  for (const [key, id] of Object.entries(opts.pins)) if ((makers.get(key) ?? []).some((lp) => lp.id === id)) pins.set(key, id);
  const dropped: StuffKey[] = [];
  for (;;) {
    const settled = settleOnce(graph, opts, pins);
    const stuck = [...pins.keys()].sort(byString)
      .find((key) => !settled.cost.has(key) && (makers.get(key) ?? []).some((lp) => lp.id !== pins.get(key)));
    if (stuck === undefined) return { ...settled, droppedPins: dropped };
    pins.delete(stuck);
    dropped.push(stuck);
  }
}

/**
 * Why `key`, which the breakdown needs but which never settled, is unmade (architecture §11 entry 41 (2)): `own-chain` when
 * a recipe of the book for it consumes an unsettled good from which the book's recipes lead back to it — every way to it
 * needs a part of its own chain — else `no-recipe` (the book holds no recipe for it, or its recipes need parts nothing
 * here makes).
 */
export function unmadeCause(graph: CandidateGraph, settled: Settled, key: StuffKey): 'no-recipe' | 'own-chain' {
  const makers = makersOf(graph);
  const leadsBack = (start: StuffKey): boolean => {
    const seen = new Set<StuffKey>();
    const stack = [start];
    while (stack.length > 0) {
      const good = stack.pop() as StuffKey;
      if (good === key) return true;
      if (seen.has(good) || settled.cost.has(good)) continue;
      seen.add(good);
      for (const lp of makers.get(good) ?? []) for (const [input, c] of lp.coeffs) if (c < 0) stack.push(input);
    }
    return false;
  };
  for (const lp of makers.get(key) ?? []) {
    for (const [input, c] of lp.coeffs) if (c < 0 && !settled.cost.has(input) && leadsBack(input)) return 'own-chain';
  }
  return 'no-recipe';
}

 * The machines a one-off job may run on (architecture §11 entry 41 (1)): per mteId the group's machines of the world scan
 * (`ctx.ownedMachines`), of "Machines we have" (`settings.ownedManual`) and of every step's `owned` count, summed. Reuse
 * settings (`declineReuse`, `reuseOwned`) do not apply: they keep a machine out of the running line, not out of a one-off
 * job. Only whether a type is there is read.
 */
export function ownedForParts(ctx: PlanContext, settings: PlanSettings, steps: readonly PlanStep[]): Map<number, number> {

}

/**

 * the furnace for `furnace`; else, of the map's machines that run `r` at `groupTier` (`pickMachine`'s rule: a singleblock of
 * a tier at most `groupTier` whose `V[tier]` × the map's amps covers the recipe's EU/t, any multiblock of the map), the first
 * of: one the group has (`owned`; highest tier, then lowest mteId) → `owned`; one this line builds (`line`) and `exclude`
 * leaves in (highest tier, lowest mteId) → `line`; a singleblock not in `exclude` (lowest tier, lowest mteId: the cheapest
 * to build) → `new`; a multiblock not in `exclude` (one of `multiblocks` first, lowest mteId) → `new`; one of `exclude`
 * (lowest tier, lowest mteId) → `first`. Null when none runs it.
 */
export function partMachine(
  pack: Pack, r: Recipe, mapId: string,
  opts: { groupTier: number; owned: ReadonlyMap<number, number>; line: ReadonlySet<number>; exclude?: ReadonlySet<number>; multiblocks?: ReadonlySet<number> },
): BomMachine | 'crafting table' | null {
  if (mapId === 'crafting') return 'crafting table';
  if (mapId === 'furnace') return { mteId: PSEUDO_MACHINES.FURNACE, name: 'Furnace', tier: 0, source: 'owned' };
  const amps = pack.maps.get(mapId)?.amps ?? 1;
  const runs = (pack.machinesByMap.get(mapId) ?? []).flatMap((id) => pack.machines.get(id) ?? [])
    .filter((m) => m.kind === 'multiblock' || (m.kind === 'basic' && tierOf(m) <= opts.groupTier && (V[tierOf(m)] as number) * amps >= r.euPerTick));
  const exclude = opts.exclude ?? new Set<number>();
  const highest = (a: Machine, b: Machine): number => tierOf(b) - tierOf(a) || a.mteId - b.mteId;
  const lowest = (a: Machine, b: Machine): number => tierOf(a) - tierOf(b) || a.mteId - b.mteId;
  const as = (m: Machine | undefined, source: BomMachine['source']): BomMachine | undefined =>
    m === undefined ? undefined : { mteId: m.mteId, name: m.name, tier: tierOf(m), source };
  const multis = (list: Machine[]): Machine[] => list.filter((m) => m.kind === 'multiblock')
    .sort((a, b) => Number(!(opts.multiblocks?.has(a.mteId) ?? true)) - Number(!(opts.multiblocks?.has(b.mteId) ?? true)) || a.mteId - b.mteId);
  return as(runs.filter((m) => (opts.owned.get(m.mteId) ?? 0) > 0).sort(highest)[0], 'owned')
    ?? as(runs.filter((m) => opts.line.has(m.mteId) && !exclude.has(m.mteId)).sort(highest)[0], 'line')
    ?? as(runs.filter((m) => m.kind === 'basic' && !exclude.has(m.mteId)).sort(lowest)[0], 'new')
    ?? as(multis(runs.filter((m) => !exclude.has(m.mteId)))[0], 'new')
    ?? as(runs.filter((m) => exclude.has(m.mteId)).sort(lowest)[0], 'first')
    ?? null;
}

/** The pooled make plan of a build list (`poolMakes`). */
export interface Pooled {
  /** Whole runs of every made good. */
  runs: Map<StuffKey, number>;
  /** What the whole list needs of every good. */
  demand: Map<StuffKey, number>;
  /** Goods that are not made: the pooled totals. */
  leaves: Map<StuffKey, number>;
  /** Leaf → top-level key → that top's exact share (fractional runs). */
  shares: Map<StuffKey, Map<StuffKey, number>>;
  /** [consumer, input] where the input was on the walk's stack, sorted (its demand there is gathered). */
  backEdges: Array<[StuffKey, StuffKey]>;
}

/**
 * The pooled make plan of a whole build list (architecture §11 entry 41 (4)): depth first from `tops` in order through
 * `made(key)?.inputs` (post order; an input already on the stack is a back edge, its demand gathered); every top's amount on
 * its key; then consumers first (the post order reversed) a made good with demand d above TINY runs ceil(d / perRun − TINY)
 * times and adds per-run × runs to each input's demand (a back edge's to `leaves`), and a good `made` gives null for adds
 * its d to `leaves`. Shares: the same walk from each top alone with fractional runs, adding each leaf amount to
 * `shares[leaf][top]`. Values `round9`.
 */
export function poolMakes(tops: ReadonlyArray<{ key: StuffKey; amount: number }>, made: (key: StuffKey) => PoolGood | null): Pooled {
  const order: StuffKey[] = [];
  const state = new Map<StuffKey, 'open' | 'done'>();
  const back = new Set<string>();
  const backEdges: Array<[StuffKey, StuffKey]> = [];
  const memo = new Map<StuffKey, PoolGood | null>();
  const madeOf = (key: StuffKey): PoolGood | null => {
    if (!memo.has(key)) memo.set(key, made(key));
    return memo.get(key) as PoolGood | null;
  };
  const visit = (key: StuffKey): void => {
    state.set(key, 'open');
    for (const [input] of madeOf(key)?.inputs ?? []) {
      const s = state.get(input);
      if (s === 'open') {
        const id = `${key}\u0000${input}`;
        if (!back.has(id)) {
          back.add(id);
          backEdges.push([key, input]);
        }
        continue;
      }
      if (s === undefined) visit(input);
    }
    state.set(key, 'done');
    order.push(key);
  };
  for (const t of tops) if (!state.has(t.key)) visit(t.key);
  const isBack = (from: StuffKey, to: StuffKey): boolean => back.has(`${from}\u0000${to}`);
  const pass = (start: ReadonlyArray<{ key: StuffKey; amount: number }>, whole: boolean): Pick<Pooled, 'runs' | 'demand' | 'leaves'> => {
    const demand = new Map<StuffKey, number>();
    const runs = new Map<StuffKey, number>();
    const leaves = new Map<StuffKey, number>();
    const add = (map: Map<StuffKey, number>, key: StuffKey, n: number): void => {
      map.set(key, (map.get(key) ?? 0) + n);
    };
    for (const t of start) add(demand, t.key, t.amount);
    for (const key of [...order].reverse()) {
      const d = demand.get(key) ?? 0;
      if (d <= TINY) continue;
      const m = madeOf(key);
      if (m === null) {
        add(leaves, key, d);
        continue;
      }
      const n = whole ? Math.ceil(d / m.perRun - TINY) : d / m.perRun;
      runs.set(key, n);
      for (const [input, per] of m.inputs) add(isBack(key, input) ? leaves : demand, input, per * n);
    }
    return { runs, demand, leaves };
  };
  const pooled = pass(tops, true);
  const shares = new Map<StuffKey, Map<StuffKey, number>>();
  for (const t of tops) {
    for (const [leaf, n] of pass([t], false).leaves) {
      const byTop = shares.get(leaf) ?? new Map<StuffKey, number>();
      byTop.set(t.key, round9((byTop.get(t.key) ?? 0) + n));
      shares.set(leaf, byTop);
    }
  }
  const rounded = (map: Map<StuffKey, number>): Map<StuffKey, number> => new Map([...map].map(([k, v]) => [k, round9(v)]));
  backEdges.sort(([a, b], [c, d]) => byString(a, c) || byString(b, d));
  return { runs: rounded(pooled.runs), demand: rounded(pooled.demand), leaves: rounded(pooled.leaves), shares, backEdges };
}

 * gives a good's recipe, `no-recipe` when no machine runs its recipe here, or its unmade cause; `madeOf` a node's `BomMade`;
 * `alternatives` the swap list of every good the lines make, its recipes at a finite gross cost.
 */
function madeParts(pack: Pack, lines: readonly BomLine[], x: Expansion, book: RecipeBook, isLeaf: (key: StuffKey) => boolean): {
  how(key: StuffKey): How; madeOf(key: StuffKey, lp: LpRecipe, runs: number): BomMade; alternatives(): Map<StuffKey, PlanStep['alternatives']>;
} {
  const steps = x.steps ?? [];
  const owned = ownedForParts(x.ctx, x.settings, steps);
  const line = new Set(steps.filter((s) => s.count > s.owned && !PSEUDO_IDS.has(s.machine.mteId)).map((s) => s.machine.mteId));
  const reach = (start: StuffKey): Set<StuffKey> => {
    const seen = new Set<StuffKey>();
    const stack = [start];
    while (stack.length > 0) {
      const key = stack.pop() as StuffKey;
      if (seen.has(key)) continue;
      seen.add(key);
      const c = book.chosen(key);
      if (c !== undefined) for (const [input] of book.inputsOf(c.lp)) stack.push(input);
    }
    return seen;
  };
  const exclude = new Map<StuffKey, Set<number>>();
  for (const mteId of [...line].sort((a, b) => a - b)) {
    const m = pack.machines.get(mteId);
    if (m === undefined) continue;
    const own = new Set([m.itemKey, ...structureParts(pack, m).keys()]);
    for (const top of lines) {
      if (!own.has(top.key)) continue;
      for (const key of reach(top.key)) {
        const set = exclude.get(key) ?? new Set<number>();
        set.add(mteId);
        exclude.set(key, set);
      }
    }
  }
  const machines = new Map<StuffKey, BomMade['machine'] | null>();
  const machineOf = (key: StuffKey, lp: LpRecipe): BomMade['machine'] | null => {
    if (!machines.has(key)) {
      const r = pack.recipeById.get(lp.id);
      machines.set(key, r === undefined || lp.mapId === null ? null : partMachine(pack, r, lp.mapId, {
        groupTier: x.env.tier, owned, line, exclude: exclude.get(key) ?? new Set(), ...(x.env.multiblocks === undefined ? {} : { multiblocks: x.env.multiblocks }),
      }));
    }
    return machines.get(key) as BomMade['machine'] | null;
  };
  const how = (key: StuffKey): How => {
    if (isLeaf(key)) return undefined;
    const c = book.chosen(key);
    if (c === undefined) return book.unmade(key);
    return machineOf(key, c.lp) === null ? 'no-recipe' : c;
  };
  const madeOf = (key: StuffKey, lp: LpRecipe, runs: number): BomMade => {
    const r = pack.recipeById.get(lp.id);
    const made: BomMade = { recipeId: lp.id, mapId: lp.mapId as string, machine: machineOf(key, lp) as BomMade['machine'], runs };
    const circuit = r === undefined ? undefined : recipeCircuit(r);
    if (circuit !== undefined) made.circuit = circuit;
    const held = (r?.inputs ?? []).flatMap((ing) => {
      const option = ing.consumed ? undefined : heldOption(ing.options);
      if (option === undefined) return [];
      if (circuit !== undefined && !isFluidKey(option.key) && parseItemKey(option.key).id === PROGRAMMED_CIRCUIT_ID) return [];
      return [option.key];
    });
    if (held.length > 0) made.nonConsumed = held;
    if (lp.needsCleanroom) made.cleanroom = true;
    return made;
  };
  const alternatives = (): Map<StuffKey, PlanStep['alternatives']> => {
    const out = new Map<StuffKey, PlanStep['alternatives']>();
    // The goods the lines make, through the recipes they are made by (not through a good no machine here makes).
    const made = new Set<StuffKey>();
    const stack = lines.map((l) => l.key);
    while (stack.length > 0) {
      const key = stack.pop() as StuffKey;
      const h = how(key);
      if (made.has(key) || typeof h !== 'object') continue;
      made.add(key);
      for (const [input] of book.inputsOf(h.lp)) stack.push(input);
    }
    for (const key of [...made].sort(byString)) {
      // Finite costs only, as a step's swap list (entry 41 (3)): a recipe above a base material out of reach costs
      // Infinity, which JSON sends as null; a good left with no row gets no swap list.
      const list = book.producersOf(key).filter((p) => Number.isFinite(p.cost));
      if (list.length > 0) out.set(key, list.map((p) => ({ recipeId: p.lp.id, rawCost: round6(p.cost), mapId: p.lp.mapId as string, ...recipeParts(pack, p.lp.id, new Set()) })));
    }
    return out;
  };
  return { how, madeOf, alternatives };
}

/**
 * The breakdown `buildBom` and `expandBomLines` share, so the two can never differ (architecture §11 entry 41 (1)–(3)).
 * Each line keeps its key, amount, why and group and gets what storage holds of it. A good is a leaf when it is a free
 * input (`freeLeaves`: always, even where the line itself plans its generator), when the line can buy it, or when it is a
 * base material out of reach (the material itself is what the group must unlock, as solve.ts names it). Every other good
 * is made one way across the whole list, by the recipe the book settled for it (`settleRecipes`: cheapest first from the
 * leaves, at gross cost, a pinned good by its pin while that settles it), on the machine `madeParts` picks — or it is
 * `unmade`, by cause. A made node has `made` and `ceil(amount / made per run)` runs, whose consumed inputs × runs are its
 * children (sorted by key, ruling R7); the tree stops at `MAX_DEPTH`, where a node keeps its `made` and has no children.
 * `totals` sums the leaves and unmade nodes per key, sorted by key, each with the top-level lines that need it
 * (`neededFor`, fix spec D15: by key, in the order of the lines) and the why "for <their names>", each name once (ruling
 * P18); `alternatives` the swap list of every made good. `warnings` holds the graph's `graph-too-big`, in the build list's
 * words, when the graph hit its recipe cap.
 */
async function expandWith(
  pack: Pack, lines: readonly BomLine[], expansion: Expansion,
): Promise<{ lines: BomLine[]; totals: BomLine[]; warnings: PlanWarning[]; alternatives: Map<StuffKey, PlanStep['alternatives']> }> {
  const x: Expansion = { ...expansion, leaf: freeLeaves(pack, expansion) };
  const leafKeys = new Map<StuffKey, boolean>();
  const isLeaf = (key: StuffKey): boolean => {
    let leaf = leafKeys.get(key);
    if (leaf === undefined) {
      const d = x.leaf(key);
      leaf = d.buyable || d.leafClass === 'unavailable';
      leafKeys.set(key, leaf);
    }
    return leaf;
  };
  const targets = [...new Set(lines.map((l) => l.key))].filter((key) => !isLeaf(key));
  const book = targets.length > 0 ? await recipeBook(pack, x, targets, isLeaf) : NO_RECIPES;
  const parts = madeParts(pack, lines, x, book, isLeaf);
  const totals = new Map<StuffKey, number>();
  /** Per total, what each top-level line (by key, first need first) needs of it. */
  const neededBy = new Map<StuffKey, Map<StuffKey, number>>();
  const node = (line: BomLine, depth: number, top: StuffKey): BomLine => {
    const out: BomLine = { key: line.key, amount: line.amount, why: line.why };
    if (line.group !== undefined) out.group = line.group;
    const have = haveOf(x.ctx, line.key);
    if (have !== undefined) out.have = have;
    if (line.amount <= TINY) return out;   // nothing to make, nothing to gather
    const how = parts.how(line.key);
    if (typeof how !== 'object') {
      if (how !== undefined) out.unmade = how;
      totals.set(line.key, (totals.get(line.key) ?? 0) + line.amount);
      const byTop = neededBy.get(line.key) ?? new Map<StuffKey, number>();
      byTop.set(top, (byTop.get(top) ?? 0) + line.amount);
      neededBy.set(line.key, byTop);
      return out;
    }
    const runs = Math.ceil(line.amount / how.perRun - TINY);
    out.made = parts.madeOf(line.key, how.lp, runs);
    if (depth >= MAX_DEPTH) return out;   // the tree stops here; the choices below it still stand
    const why = `for ${pack.nameOf(line.key)}`;
    const children = book.inputsOf(how.lp).map(([input, perRun]) => node({ key: input, amount: round9(perRun * runs), why }, depth + 1, top));
    if (children.length > 0) out.children = children;
    return out;
  };
  const expanded = lines.map((line) => node(line, 0, line.key));
  return {
    warnings: book.warnings,
    lines: expanded,
    totals: [...totals].sort(([a], [b]) => byString(a, b)).map(([key, amount]) => {
      const neededFor = [...(neededBy.get(key) ?? [])].map(([top, n]) => ({ key: top, amount: round9(n) }));
      // Each name once: the programmed circuits of several configurations are all "Programmed Circuit".
      const names = [...new Set(neededFor.map((n) => pack.nameOf(n.key)))];
      const total: BomLine = { key, amount: round9(amount), why: `for ${names.join(', ')}`, neededFor };
      const how = parts.how(key);
      if (typeof how === 'string') total.unmade = how;
      const have = haveOf(x.ctx, key);
      if (have !== undefined) total.have = have;
      return total;
    }),
    alternatives: parts.alternatives(),
  };
}

- `<qty>` of a made part is its make's `amount` (pooled: a top-level line that is also an intermediate shows the whole amount); of an unmade one its pooled total. `<suffix>` is today's one-off wording, ` (stays in the machine)` or ` (a tool for hand-crafting)`, for a part whose first top-level line is in the one-off group, else empty. `<inputs>`: the make's inputs as `<qty>`, by key, joined by `, ` (no inputs: ` from <inputs>` is left out). `<tier>`: `tierName(tier)`. - `<machine>`: `owned` → `your <name>`; `line` → `the <name> this line builds`; `new` and `first` → `withArticle(<name>)` ("a Basic Wiremill", "an Advanced Assembler", "an Electric Blast Furnace").

- The held parts and tools a step names (`with … in it`, `(tools: …)`) are no build-list lines, and a cleanroom job adds no cleanroom line (change request 9; the controller's ruling on open question 1): the group makes or borrows them.
- `gather` names the totals that are not `unmade` (today's text and `GATHER_SHOWN` cut otherwise).
- **Order** (the algorithm the copy does not fix): one node per key — every make, every unmade total, every other top-level line; a node waits for the keys of its `after` that are nodes (a bought line has none). Kahn's walk: of the ready nodes take the one with the same machine key as the node just taken, else the smallest machine key, then name, then key (plain string order); machine key = `''` for `gather`-kind and today's-text nodes, `'crafting table'` for crafting, else the machine's name. Every round takes one node, so the walk always ends.

/**
 * The build steps of the build list's parts (architecture §11 entry 41 (5), the copy table of add-on 14's Task 5): the
 * gather step for the totals that are not unmade, then one step per part — every make, every unmade total, every other
 * top-level line (a key's first top-level line carries its step and id) — in Kahn's order of their waits (`BomMake.after`),
 * batched by machine; a cycle through machines this line builds drops the machine waits of its smallest node and words
 * that job's machine as `first`.
 */
export function partSteps(
  pack: Pack, input: { steps: readonly PlanStep[]; bom: { lines: BomLine[]; totals: BomLine[]; makes?: readonly BomMake[] }; tier: number; avoid?: HeldAvoid },
): Array<Omit<BuildStep, 'order'>> {
  const { steps, bom, tier, avoid } = input;
  const qty = (key: StuffKey, n: number): string => (isFluidKey(key) ? `${amountText(n)} L ${partName(pack, key)}` : `${amountText(n)}× ${partName(pack, key)}`);
  const out: Array<Omit<BuildStep, 'order'>> = [];
  const gathered = bom.totals.filter((t) => t.unmade === undefined);
  if (gathered.length > 0) {
    const shown = gathered.slice(0, GATHER_SHOWN).map((l) => qty(l.key, l.amount)).join(', ');
    const more = gathered.length - GATHER_SHOWN;
    out.push({ id: 'gather', kind: 'gather', text: `Gather the base materials: ${shown}${more > 0 ? ` (and ${more} more)` : ''}` });
  }
  const roomKey = cleanroomMachine(pack)?.itemKey;
  // Task 13 ruling: a one-off that is only a hand-crafting tool (no step keeps it in a machine) is worded as a tool.
  const machineParts = new Set(steps.flatMap((s) => stepOneOffs(pack, s, avoid).map((o) => o.key)));
  const toolsOnly = new Set(steps.flatMap((s) => stepTools(pack, s, avoid)).filter((key) => !machineParts.has(key)));
  const firstTop = new Map<StuffKey, BomLine>();
  /** What all the top-level lines of a key ask for: a bought part's one step names every group's amount. */
  const topAmount = new Map<StuffKey, number>();
  for (const l of bom.lines) {
    if (!firstTop.has(l.key)) firstTop.set(l.key, l);
    topAmount.set(l.key, (topAmount.get(l.key) ?? 0) + l.amount);
  }
  const suffix = (key: StuffKey): string => {
    const top = firstTop.get(key);
    if (top === undefined || (top.group ?? 'machines') !== 'one-off') return '';
    return toolsOnly.has(key) ? ' (a tool for hand-crafting)' : ' (stays in the machine)';
  };
  const idOf = (key: StuffKey): string => (firstTop.has(key) ? `craft:${key}` : `make:${key}`);
  type Node = {
    key: StuffKey; id: string; kind: BuildStep['kind']; machineKey: string; name: string;
    waits: Set<StuffKey>; machineWaits: Set<StuffKey>; text(first: boolean): string;
  };
  const nodes = new Map<StuffKey, Node>();
  for (const m of bom.makes ?? []) {
    const machine = m.made.machine;
    const name = partName(pack, m.key);
    const what = `${qty(m.key, m.amount)}${suffix(m.key)}`;
    const from = m.inputs.length === 0 ? '' : ` from ${m.inputs.map((i) => qty(i.key, i.amount)).join(', ')}`;
    const held = (m.made.nonConsumed ?? []).map((k) => partName(pack, k));
    const machineWaits = new Set<StuffKey>();
    if (typeof machine === 'object' && machine.source === 'line') {
      const own = pack.machines.get(machine.mteId);
      if (own !== undefined) for (const k of [own.itemKey, ...structureParts(pack, own).keys()]) if (m.after.includes(k)) machineWaits.add(k);
    }
    const text = (first: boolean): string => {
      if (machine === 'crafting table') return `Craft ${what}${from} at a crafting table${held.length > 0 ? ` (tools: ${held.join(', ')})` : ''}`;
      const source = first ? 'first' : machine.source;
      const where = source === 'owned' ? `your ${machine.name}` : source === 'line' ? `the ${machine.name} this line builds` : withArticle(machine.name);
      const config: string[] = [];
      if (m.made.circuit !== undefined) config.push(`circuit ${m.made.circuit}`);
      if (held.length > 0) config.push(`with ${held.join(', ')} in it`);
      if (m.made.cleanroom === true) config.push('in a cleanroom');
      if (source === 'line') config.push('place and power it first');
      if (source === 'new') config.push(`you have none and this line builds none: build one, or import the ${name}`);
      if (source === 'first') config.push(`the one this line builds needs it first: use another one, or import the ${name}`);
      return `Make ${what}${from} in ${where}${config.length > 0 ? ` (${config.join('; ')})` : ''}`;
    };
    nodes.set(m.key, {
      key: m.key, id: idOf(m.key), kind: machine === 'crafting table' ? 'craft' : 'make',
      machineKey: machine === 'crafting table' ? 'crafting table' : machine.name, name, waits: new Set(m.after), machineWaits, text,
    });
  }
  for (const t of bom.totals) {
    if (t.unmade === undefined || nodes.has(t.key)) continue;
    const what = `${qty(t.key, t.amount)}${suffix(t.key)}`;
    const text = t.unmade === 'own-chain'
      ? `Get ${what}: every recipe for it here needs a part of its own chain, so swap the recipe of a part it goes into, or import it (mark it "we already make this")`
      : `Get ${what}: nothing at ${tierName(tier)} can make it, so import it (mark it "we already make this")`;
    nodes.set(t.key, { key: t.key, id: idOf(t.key), kind: 'gather', machineKey: '', name: partName(pack, t.key), waits: new Set(), machineWaits: new Set(), text: () => text });
  }
  for (const l of firstTop.values()) {
    if (nodes.has(l.key)) continue;
    const group = l.group ?? 'machines';
    const amount = qty(l.key, topAmount.get(l.key) ?? l.amount);
    const text = group === 'one-off' && toolsOnly.has(l.key) ? `Make ${amount} (a tool for hand-crafting)`
      : group === 'one-off' ? `Make ${amount} (stays in the machine)`
      : group === 'machines' && l.key === roomKey ? `Build a cleanroom (${partName(pack, l.key)}) around the steps that need it`
      : `Craft ${amount}`;
    nodes.set(l.key, { key: l.key, id: `craft:${l.key}`, kind: 'craft', machineKey: '', name: partName(pack, l.key), waits: new Set(), machineWaits: new Set(), text: () => text });
  }
  for (const n of nodes.values()) {
    for (const w of [...n.waits]) if (!nodes.has(w)) n.waits.delete(w);

    done.add(pick.key);
    last = pick;
    out.push({ id: pick.id, kind: pick.kind, text: pick.text(first) });
  }
  return out;
}
