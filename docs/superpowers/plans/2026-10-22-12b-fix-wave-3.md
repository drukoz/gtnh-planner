# Add-on 12 Fix Wave 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Before add-on 12's final review, give the build stage (1) a robust, deterministic build-MIP pick (F), (2) item
prices that do not depend on the keys asked with them and never rise when a cost override gets cheaper (D), (3) the
user's per-project raw cap — "still pick fewest machines, but never more than 25 % more raw material than the leanest
line" — measured against the plan "Least raw material" makes, with the step charge re-based on that line where it is
far above S1 (A), (B2), and MV circuit's Phosphate Dust pinned to the group's stock (C; its fix is open question 2), (4) "Only these come in" (B), and (5) a shared
recipe-acceptance memo and the wave's timing re-pins (E) — without changing what "Ignore build cost" plans.

**Architecture:** (F) `pickBuild` (solve.ts) solves the build MIP with 50 nodes and strong branching off, so the
50,000-iteration cap bounds every node; a solve whose root LP relaxation has no finite bound stops itself and runs again
at a 1e-9 tolerance; the decision is the cheapest by `exactCost` of every improving solution HiGHS reported (lp.ts gains
`highsOptions` and four optional `LpModel` fields). (D) `itemPrices` (build-cost.ts) prices every key on one price graph
per pricing context (`priceGraph`, walked from `priceKeys(pack, tier)`, united with the no-override walk when overrides
exist) at the least raw material that makes one unit of it on its own (`standalonePrices`, solve.ts, all keys of a call
on one hot-started HiGHS model: `solveLpRows`, lp.ts), memoized per context and key; a key whose dead ends together would
not make it stays a pricing gap. (A)/(B2) `buildStage` first solves the same build MIP at step charge 0 (the leanest
line, `leanestLine`); one more row caps the plan's raw material at (1 + `rawCap`) × that line's; the step charge becomes
`stepCharge × leanRaw × F` where that is more than `LEAN_BASE_ABOVE` × σ; under the cap plan 09's plan is one more start,
and the leanest line's plan and plan 09's are kept where cheaper by `exactCost` (`cheaperPlan`, ruling 187). `PlanSettings.rawCap` (default 0.25, null = no limit)
arrives through a settings-version-4 "Planner update"; the client gets "Raw material for fewer machines" and a banner
measured against the leanest line. (B) `PlanSettings.inputsOnly`: `makeLeafOracle` returns a non-leaf for every key
outside a non-empty list that is no free input; blockers say "Nothing makes <good> from your base materials"; the build
list and layout parts break down with `LinePricing.buildLeaf` (the oracle without the list); Settings gets a chip list.
(E) `acceptOf` (candidates.ts) remembers `acceptRecipe` per pack and acceptance context for every candidate walk; the last
task re-times every real-data case on a quiet host.

### (F) robust MIP pick and (E) plan time

The build MIP stops after its root node (`BUILD_MIP_MAX_NODES = 1`) at `mip_feasibility_tolerance` 1e-10. Two things
make that pick fragile (measured on plan/12 a5f5100, whose `src/` is 737bcd0's; evidence file `ev-mip.md`, items 1-9).
(1) On Good Electronic Circuit 2/min HV on AE2 (10,001 rows, 5,321 integers) HiGHS cannot solve the root LP relaxation
at 1e-10: the dual bound is still -inf at the first interrupt checkpoint after 3,341 simplex iterations, so the root runs

```ts
/** Whether a build MIP's result is a plan: it has a whole solution and the time guard did not stop it. */
function wholeBuild(r: LpResult): boolean {
  return r.status === 'optimal' || (r.status === 'feasible' && r.stop !== 'time');
}

/**
 * The build MIP's solve and its pick (fix wave 3 (F), ledger 248): robust and still decided by node and simplex-iteration
 * limits only. One solve from `start` — BUILD_MIP_MAX_NODES nodes without strong branching (whose iterations escape the
 * iteration cap) within BUILD_MIP_MAX_LP_ITERATIONS — that stops itself when its root LP relaxation does not solve at
 * MIP_FEASIBILITY_TOLERANCE (`stopOnRootLpFailure`) and then runs again at BUILD_MIP_RETRY_TOLERANCE from the same
 * start. The decision is the cheapest by `exactCost` (every machine at its true build) of the whole solutions HiGHS
 * reported on the way (`keepImproving`), of both solves: HiGHS ranks them by the model, whose light steps are off by less
 * than a machine each, and on 2 of 66 measured lines an earlier one is cheaper; ties keep HiGHS's last. A solve the time
 * guard stops gives nothing: when the last solve is no plan, `buildStage` falls back as before. The result is the last
 * solve's, with `x` the pick. `model` is the model solved: `mip.model`, or one a caller derived from it for `start`.
 */
async function pickBuild(
  mip: ReturnType<typeof buildMip>, start: number[] | undefined, opts: SolveOptions, limit: number, model: LpModel = mip.model,
): Promise<{ result: LpResult; retried?: true; earlier?: true }> {
  const solve = (tolerance?: number): Promise<LpResult> => solveLp({
    ...model, ...(start === undefined ? {} : { start }),
    maxNodes: opts.buildMaxNodes ?? BUILD_MIP_MAX_NODES, maxIterations: opts.buildMaxIterations ?? BUILD_MIP_MAX_LP_ITERATIONS, timeLimit: limit,
    strongBranching: false, keepImproving: true,
    ...(tolerance === undefined ? { stopOnRootLpFailure: true } : { feasibilityTolerance: tolerance }),
  });
  const first = await solve();
  const runs = [first];
  if (first.rootLpFailed === true) runs.push(await solve(BUILD_MIP_RETRY_TOLERANCE));
  const result = runs[runs.length - 1] as LpResult;
  const retried = runs.length > 1 ? { retried: true as const } : {};
  if (!wholeBuild(result)) return { result, ...retried };
  let best = { x: result.x, cost: mip.exactCost(result.x) };
  for (const r of runs) {
    for (const x of r.improving ?? []) {
      const cost = mip.exactCost(x);
      if (cost < best.cost * (1 - 1e-9) - 1e-12) best = { x, cost };
    }
  }
  return { result: { ...result, x: best.x }, ...retried, ...(best.x !== result.x ? { earlier: true as const } : {}) };
}
```

```ts

/** One solve of a series (`solveLpRows`): row `row` held to `[lower, upper]`, every other row as the model has it. */
export interface RowBounds { row: number; lower: number; upper: number }
/** Solves of a series run on one HiGHS model before the event loop gets a turn and the model is passed again. */
export const LP_ROWS_PER_MODEL = 64;

/**
 * `model` (an LP: no `integer`, `start` or limits) solved once per entry of `changes`, each with that entry's row held to
 * its bounds and every other row as `model` has it, in order: status and objective of each. One HiGHS model serves
 * `LP_ROWS_PER_MODEL` solves, each started from the basis the solve before it left (HiGHS keeps it when only row bounds
 * change; presolve off), so a series that differs in one row — the least raw that makes one unit of each good of a price
 * graph, its row's demand 1 — takes a few simplex iterations per solve instead of a solve from scratch (fix wave 3 (D):
 * 3–11 ms a good on the 2.9 export's price graphs, LV to IV); the event loop runs between the models. Bounds are scaled as
 * `modelData` scales the row.
 */
export async function solveLpRows(model: LpModel, changes: readonly RowBounds[]): Promise<Array<Pick<LpResult, 'status' | 'objective'>>> {
  const out: Array<Pick<LpResult, 'status' | 'objective'>> = [];
  if (model.colCost.length === 0) {
    for (const change of changes) {
      const rows = model.rows.map((row, i) => (i === change.row ? { ...row, lower: change.lower, upper: change.upper } : row));
      const { status, objective } = solveEmpty({ ...model, rows });
      out.push({ status, objective });
    }
    return out;
  }
  for (let first = 0; first < changes.length; first += LP_ROWS_PER_MODEL) {
    await yieldToEventLoop();
    const highs = await runtime();
    const data = modelData(highs, model);
    const statuses = highs.constants.modelStatus;
    const scaleOf = (row: number): number => 1 / Math.max(1, ...(model.rows[row]?.entries ?? []).map(([, c]) => Math.abs(c)));
    highs.withModel((m) => {
      m.options.set({ output_flag: false, presolve: 'off' });
      m.passModel(data);
      for (const change of changes.slice(first, first + LP_ROWS_PER_MODEL)) {
        const row = model.rows[change.row];
        if (row === undefined) throw new RangeError(`LP series: row ${change.row} is not in 0..${model.rows.length - 1}`);
        const s = scaleOf(change.row);
        m.changeRowBounds(change.row, change.lower * s, change.upper * s);
        let status: LpResult['status'] = 'error';
        try {
          m.run();
          const code = m.getModelStatus();
          status = code === statuses.optimal ? 'optimal' : code === statuses.infeasible ? 'infeasible'
            : code === statuses.unbounded || code === statuses.unboundedOrInfeasible ? 'unbounded' : 'error';
        } catch {
          status = 'error';
        }
        out.push({ status, objective: status === 'optimal' ? m.getObjectiveValue() : NaN });
        m.changeRowBounds(change.row, row.lower * s, row.upper * s);
      }
    });
  }
  return out;
}
```

```ts
/**
 * The recipes of `graph` that the chains of `keys` can use: each recipe that makes one of them, then each recipe that
 * makes a good one of those takes, and so on. A recipe outside them makes only goods none of those recipes take, so the
 * least raw material that makes one of `keys` is the same on them as on the whole graph.
 */
export function chainRecipes(graph: CandidateGraph, keys: readonly StuffKey[]): LpRecipe[] {
  const producers = producersIn(graph);
  const seen = new Set<StuffKey>(keys);
  const queue = [...seen];
  const used = new Set<LpRecipe>();
  while (queue.length > 0) {
    for (const r of producers.get(queue.pop() as StuffKey) ?? []) {
      if (used.has(r)) continue;
      used.add(r);
      for (const [key, c] of r.coeffs) {
        if (c < 0 && !seen.has(key)) {
          seen.add(key);
          queue.push(key);
        }
      }
    }
  }
  return graph.recipes.filter((r) => used.has(r));
}

/**
 * The least raw material that makes one unit of each of `keys` on its own in `graph` (fix wave 3 (D)): `standaloneCosts`'
 * LP — the main LP's rows with that one demand, every byproduct sunk — without its barred inputs and its chain details,
 * all of them on one model through `solveLpRows`, on the recipes their chains can use (`chainRecipes`), to 9
 * significant digits (`sig9`). So each price depends on `graph` and its leaf costs only, never on the other keys asked
 * (the solves of one series start from each other's bases, so unrounded they could differ in the last bits), and never
 * rises when a leaf gets cheaper. Infinity for a key that is no good of `graph` or that it cannot make.
 */
export async function standalonePrices(graph: CandidateGraph, keys: readonly StuffKey[]): Promise<Map<StuffKey, number>> {
  const out = new Map<StuffKey, number>();
  const lp = mainLp(graph, chainRecipes(graph, keys), new Map());
  const rowOf = new Map(lp.goods.map((key, g) => [key, g]));
  const asked = [...new Set(keys)].filter((key) => {
    if (rowOf.has(key)) return true;
    out.set(key, Infinity);
    return false;
  });
  const width = lp.rawCost.length;
  const results = await solveLpRows(
    { sense: 'min', colCost: [...lp.rawCost], colLower: new Array<number>(width).fill(0), colUpper: new Array<number>(width).fill(Infinity), rows: lp.rows },
    asked.map((key) => ({ row: rowOf.get(key) as number, lower: 1, upper: 1 })),
  );
  asked.forEach((key, i) => {
    const r = results[i];
    out.set(key, r?.status === 'optimal' ? sig9(Math.max(0, r.objective)) : Infinity);
  });
  return out;
}
```

```ts
/** One pricing context's price graph (`priceGraph`) and the prices worked out on it so far. */
interface PriceGraph {
  s: PlanSettings; basis: ReturnType<typeof planBasis>; leaf: LeafOracle; graph: CandidateGraph;
  /** Per key asked so far: its price and the graph it was priced on (the price graph, or the key's own walk). */
  priced: Map<StuffKey, Promise<{ cost: number; graph: CandidateGraph }>>;

const GRAPHS = new WeakMap<Pack, Map<string, Promise<PriceGraph>>>();

/** `memo.get(key)`, made the most recently used; else `make()` kept, at most MACHINE_PRICE_MEMO_SIZE, dropped when it fails. */
function memoized<T>(memo: Map<string, Promise<T>>, key: string, make: () => Promise<T>): Promise<T> {
  const hit = memo.get(key);
  if (hit !== undefined) {
    memo.delete(key);
    memo.set(key, hit);
    return hit;
  }
  const made = make();
  memo.set(key, made);
  if (memo.size > MACHINE_PRICE_MEMO_SIZE) memo.delete(memo.keys().next().value as string);
  made.catch(() => {
    if (memo.get(key) === made) memo.delete(key);
  });
  return made;
}

/**
 * `a` with the recipes of `b` it lacks; the goods `b` adds take `leaf`'s decision (a virtual good its own). The price
 * graph of a context with cost overrides is its walk united with the walk at no overrides (`priceGraph`).
 */
function unitedGraph(a: CandidateGraph, b: CandidateGraph, leaf: LeafOracle): CandidateGraph {
  const recipes = new Map(a.recipes.map((r) => [r.id, r]));
  for (const r of b.recipes) if (!recipes.has(r.id)) recipes.set(r.id, r);
  const goods = new Map(a.goods);
  for (const [key, good] of b.goods) {
    if (goods.has(key)) continue;
    if (good.virtual) {
      goods.set(key, good);
      continue;
    }
    const { buyable, cost, leafClass } = leaf(key);
    goods.set(key, { key, buyable, cost, leafClass, virtual: false });
  }
  const united: CandidateGraph = { ...a, recipes: [...recipes.values()].sort((x, y) => byString(x.id, y.id)), goods };
  if (b.truncated === true) united.truncated = true;
  return united;
}

/** A good the price graph makes, as a leaf of an ore walk (`orePrice`): it stops the walk there, and is no leaf in the LP. */
const MADE_IN_PRICE_GRAPH: LeafDecision = { buyable: true, cost: 0, leafClass: 'derived' };
const NOT_A_PRICE_LEAF: LeafDecision = { buyable: false, cost: 0, leafClass: null };

/**
 * Fix wave 2 (c), controller ruling 187, per key (fix wave 3 (D)): the price of `key`, which `graph` cannot make, when
 * the ore blocks among its dead ends that the group can mine (`mined`) would let it be made (`makeableWith`) — on the
 * 2.9 export the Flawless Diamond of the Advanced Lathe (292) and the Advanced Macerator (302), so neither machine could
 * be weighed at MV. `key` is walked on its own with those ores as leaves at their price and every good `graph` makes as a
 * leaf that stops the walk; that walk's recipes join `graph`, where the mined ores are bought at their price, and the
 * standalone LP prices `key` there (no other key sees the ores). Infinity otherwise, and when `graph` was cut short at its
 * recipe cap (such keys stay pricing gaps).
 */
async function orePrice(pack: Pack, entry: PriceGraph, graph: CandidateGraph, key: StuffKey, mined: (key: StuffKey) => boolean): Promise<number> {
  if (graph.truncated === true || (pack.producers.get(key) ?? []).length === 0) return Infinity;
  const ores = deadEnds(graph, key).filter(mined);
  if (ores.length === 0 || !makeableWith(graph, key, ores)) return Infinity;
  const { s, basis, leaf } = entry;
  const made = graph === entry.graph && entry.makeable !== undefined ? entry.makeable : makeableGoods(graph);
  const bought = (k: StuffKey): LeafDecision => ({ buyable: true, cost: basis.prices.price(k), leafClass: basis.avail.classOf(k) });
  const oreLeaf: LeafOracle = (k) => (mined(k) ? bought(k) : made.has(k) ? MADE_IN_PRICE_GRAPH : leaf(k));
  const walk = buildCandidates(pack, s, basis.env, oreLeaf, [key]);
  const united = unitedGraph(graph, walk, (k) => (mined(k) ? bought(k) : made.has(k) ? NOT_A_PRICE_LEAF : leaf(k)));
  for (const [k, good] of united.goods) if (mined(k)) united.goods.set(k, { ...good, ...bought(k) });
  return (await standalonePrices(united, [key])).get(key) ?? Infinity;
}

/**
 * The prices of `keys` in the pricing context of `settings` in `ctx` (fix wave 3 (D)): a buyable key costs its leaf's
 * cost (the leaf oracle of the context's basis with no `supplied` option, so water, air, cobblestone and lava stay leaves
 * at 0 as in every build-material breakdown (plan 09 Task 3), and without gathered recipes, so sand and gravel are dug at
 * their price — the analysis counts no machines: free cobblestone and hammers would price them at 0); stop items are
 * leaves at their override or price. Any other key costs the least raw material that makes one unit of it on its own
 * (`standalonePrices`: its byproducts sunk) on the context's price graph (`priceGraph`), or on its own walk when the
 * price graph never reached it, or, for a part only ore processing makes, what `orePrice` gives. Each price is worked
 * out once per context and key, so it never depends on the other keys asked: the cost analysis of one candidate graph
 * per key set that this replaced (`analyzeCosts`, which shares a recipe's cost among its outputs by what else the graph
 * holds) priced the Advanced Distillery at 33.39 alone, 34.59 beside the Large Chemical Reactor and 42.40 beside it and
 * the Distillation Tower (all 42.59 now), and 16x Redstone Alloy Cable at 12.38 alone and 7.19 beside every cable.
 */
async function computePrices(pack: Pack, settings: PlanSettings, ctx: PlanContext, keys: readonly StuffKey[]): Promise<ItemPrices> {
  const entry = await priceGraph(pack, settings, ctx);
  const { s, basis, leaf, graph, priced } = entry;
  // An ore block a material line would buy here (makeLeafOracle's direct and byproduct ores).
  const mined = (key: StuffKey): boolean => {
    const reach = basis.avail.classOf(key);
    return (reach === 'direct' || reach === 'byproduct') && isOreBlock(pack, key);
  };
  const fresh = keys.filter((key) => !leaf(key).buyable && !priced.has(key));
  // a good the price graph cannot make costs Infinity without an LP (its makeable fixpoint, once per context)
  entry.makeable ??= makeableGoods(graph);
  const makeable = entry.makeable;
  const onGraph = fresh.filter((key) => graph.goods.has(key) && makeable.has(key));
  const batch = onGraph.length > 0 ? standalonePrices(graph, onGraph) : null;
  const withOre = async (key: StuffKey, cost: number, on: CandidateGraph): Promise<{ cost: number; graph: CandidateGraph }> =>
    ({ cost: Number.isFinite(cost) ? cost : await orePrice(pack, entry, on, key, mined), graph: on });
  for (const key of fresh) {
    const price = graph.goods.has(key)
      ? (batch !== null && makeable.has(key) ? batch.then((m) => withOre(key, m.get(key) ?? Infinity, graph)) : withOre(key, Infinity, graph))
      : (async () => {
        const own = buildCandidates(pack, s, basis.env, leaf, [key]);
        return withOre(key, (await standalonePrices(own, [key])).get(key) ?? Infinity, own);
      })();
    priced.set(key, price);
    price.catch(() => {
      if (priced.get(key) === price) priced.delete(key);
    });
  }
  const asked = new Map<StuffKey, { cost: number; graph: CandidateGraph }>();
  for (const key of keys) {
    const price = priced.get(key);
    if (price !== undefined) asked.set(key, await price);
  }
  const cost = (key: StuffKey): number => {
    const decision = leaf(key);
    return decision.buyable ? decision.cost : (asked.get(key)?.cost ?? Infinity);
  };
  const gaps = new Map<StuffKey, PriceGap | undefined>();
  return {
    cost,
    gap(key) {
      if (!gaps.has(key)) gaps.set(key, Number.isFinite(cost(key)) ? undefined : gapOf(pack, asked.get(key)?.graph ?? graph, key, mined));
      return gaps.get(key);
    },
  };
}

const MEMOS = new WeakMap<Pack, Map<string, Promise<ItemPrices>>>();

/**
 * The prices for building `keys` (`buildKeys`) in the pricing context of `settings` in `ctx` (`computePrices`): one
 * table per pack and memo key (module doc), for at most MACHINE_PRICE_MEMO_SIZE keys per pack, the least recently used
 * dropped first; each key's price is worked out once per context, whatever else was asked with it. Callers asking while
 * it is computed share that computation; one that fails is not kept. Any key not asked that is no leaf reads Infinity,
 * so a caller asks for every key it prices. `gap` is worked out per key when first asked.
 */
export function itemPrices(pack: Pack, settings: PlanSettings, ctx: PlanContext, keys: readonly StuffKey[]): Promise<ItemPrices> {
  const asked = [...new Set(keys)].sort(byString);
  let memo = MEMOS.get(pack);
  if (memo === undefined) {
    memo = new Map();
    MEMOS.set(pack, memo);
  }
  const key = `${machinePricingKey(settings, ctx)}|${createHash('sha1').update(asked.join('\n')).digest('hex')}`;
  return memoized(memo, key, () => computePrices(pack, settings, ctx, asked));
}
```

```ts
/** Σ rawCost × runs over the main columns of `x` (per unit of demand). */
function rawOf(lp: MainLp, x: readonly number[]): number {
  let raw = 0;
  lp.rawCost.forEach((c, j) => {
    raw += c * (x[j] ?? 0);
  });
  return raw;
}

/** Whether the runs `x` use at most `bound` raw material per unit of demand (the raw cap; S3_TOLERANCE's slack); any without one. */
function withinCap(lp: MainLp, bound: number | undefined, x: readonly number[]): boolean {
  return bound === undefined || rawOf(lp, x) <= bound * (1 + S3_TOLERANCE) + TINY;
}

/** Whether the build MIP gave an answer that is a plan (`wholeBuild`: its optimum, or a whole solution its node or iteration limit stopped). */
function wholePlan(result: LpResult | undefined): result is LpResult {
  return result !== undefined && wholeBuild(result);
}

/**
 * The build MIP from `start`, solved and picked by `pickBuild` (fix wave 3 (F): its node and simplex-iteration limits,
 * the far time guard `limit`), with its seconds and `pickBuild`'s `retried`/`earlier`; no result when `limit` ≤ 0 (the
 * fallback's tests).
 */
async function runBuildMip(
  mip: ReturnType<typeof buildMip>, start: number[] | undefined, limit: number, opts: SolveOptions,
): Promise<{ result: LpResult | undefined; seconds: number; picked: Pick<NonNullable<Solution['buildStats']>, 'retried' | 'earlier'> }> {
  if (!(limit > 0)) return { result: undefined, seconds: 0, picked: {} };
  const began = performance.now();
  const { result, ...picked } = await pickBuild(mip, start, opts, limit);
  return { result, seconds: (performance.now() - began) / 1000, picked };
}

/**
 * The MIP's start: S1 rounded up (`mip.start`) or one of `others` (runs, main columns first) rounded up, whichever costs
 * least in the MIP's own objective among those whose raw material is within `bound` (fix wave 3 (A)), with that cost
 * (add-on 17's `modelAt` bounds its source binaries by it); undefined when none is a plan.
 */
function cheapestStart(
  lp: MainLp, mip: ReturnType<typeof buildMip>, bound: number | undefined, others: ReadonlyArray<readonly number[] | null | undefined>,
): { start: number[]; cost: number } | undefined {
  let best = mip.start === undefined ? undefined : { start: mip.start, cost: mip.startCost };
  for (const x of others) {
    if (x === null || x === undefined || !withinCap(lp, bound, x)) continue;
    const at = mip.startAt(x);
    if (at !== undefined && (best === undefined || at.cost < best.cost)) best = at;
  }
  return best;
}

/**
 * Fix wave 3 (A): the cheapest of `plans` (runs, main columns first) rounded up (`rounded`: every machine at its true
 * build, by the MIP's objective), among those within the raw cap `bound` that leave no step short, where it costs less
 * than `cost` (the MIP's own answer by `exactCost`); the first on a tie; undefined when none does.
 */
function cheaperPlan(
  lp: MainLp, mip: ReturnType<typeof buildMip>, bound: number | undefined, cost: number, plans: ReadonlyArray<readonly number[] | undefined>,
): { decision: BuildDecision; from: readonly number[]; cost: number } | undefined {
  let best: { decision: BuildDecision; from: readonly number[]; cost: number } | undefined;
  for (const x of plans) {
    if (x === undefined || !withinCap(lp, bound, x)) continue;
    const r = mip.rounded(x);
    if (r.decision.short === undefined && r.cost < (best?.cost ?? cost)) best = { decision: r.decision, from: x, cost: r.cost };
  }
  return best;
}
```

```ts
/** Acceptance contexts kept per pack (fix wave 3 (E)): a plan's walks use one or two, a line with an avoid list a few more. */
export const ACCEPTANCE_MEMO_SIZE = 8;
/** Per pack, per acceptance context (`acceptanceContext`), each recipe's `acceptRecipe` answer; least recently used context dropped first. */
const ACCEPTANCES = new WeakMap<Pack, Map<string, Map<string, Acceptance>>>();
let acceptanceHits = 0;

function sortedList(values: Iterable<string | number> | undefined): Array<string | number> | null {
  return values === undefined ? null : [...values].sort((a, b) => (a < b ? -1 : a > b ? 1 : 0));
}

/** What `acceptRecipe` reads of `env` and `bench`, as a key: tier, coil heat, low gravity, excluded categories, multiblocks, from-nothing recipes, the bench line. */
function acceptanceContext(env: PlanEnv, bench: BenchLine | undefined): string {
  return JSON.stringify([env.tier, env.coilHeat, env.lowGravity, sortedList(env.excluded), sortedList(env.multiblocks), sortedList(env.fromNothing),
    bench === undefined ? null : bench.capBy ?? '']);
}

/**
 * `acceptRecipe` of `pack` at `env` and `bench`, remembered per pack and acceptance context (fix wave 3 (E)): a plan
 * walks its graph five times or more (cost model, line, machine prices, build list, ingredient options; an avoid list's
 * trials more), each of which judged every recipe it reached again.
 */
export function acceptOf(pack: Pack, env: PlanEnv, bench?: BenchLine): (r: Recipe) => Acceptance {
  let contexts = ACCEPTANCES.get(pack);
  if (contexts === undefined) ACCEPTANCES.set(pack, (contexts = new Map()));
  const key = acceptanceContext(env, bench);
  let memo = contexts.get(key);
  if (memo === undefined) {
    memo = new Map();
    if (contexts.size >= ACCEPTANCE_MEMO_SIZE) contexts.delete(contexts.keys().next().value as string);
  } else {
    contexts.delete(key);
  }
  contexts.set(key, memo);
  const known = memo;
  return (r) => {
    let a = known.get(r.id);
    if (a === undefined) {
      a = acceptRecipe(pack, r, env, bench);
      known.set(r.id, a);
    } else {
      acceptanceHits++;
    }
    return a;
  };
}

/** For tests: the acceptance contexts `pack` keeps and the answers given from memory so far (this process). */
export function acceptanceMemoStats(pack: Pack): { contexts: number; hits: number } {
  return { contexts: ACCEPTANCES.get(pack)?.size ?? 0, hits: acceptanceHits };
}
```
